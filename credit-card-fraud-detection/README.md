# Credit Card Fraud Detection

A simple web-based fraud detection dashboard built with HTML, CSS, and JavaScript.

## Features

- Analyze credit card transaction details
- Calculate fraud risk score from transaction behavior
- Show risk reasons such as high amount, unusual time, location mismatch, and failed attempts
- Display deep detection modules for behavior, location, velocity, merchant risk, and model confidence
- Review recent transactions with safe/fraud labels
- Filter high-risk and safe transactions
- Indian rupee currency formatting

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Canvas Visualization
- Responsive Web Design

## How to Run

Open `index.html` in any browser.

No installation, database, or backend server is required.

## Project Note

This project demonstrates fraud detection logic through a rule-based risk scoring model. It can be extended into a machine learning project by connecting a trained model with real transaction data.
